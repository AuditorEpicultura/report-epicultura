📷 Isi Otomatis dari Foto (Baca Teks / OCR)
Upload screenshot laporan (mis. dari Staging), sistem akan membaca teksnya lalu mencoba mengisi field Outlet, Divisi, Nama Staff, Nama Auditor, Keterangan Temuan, dan Link Staging secara otomatis. Proses baca teks terjadi langsung di browser ini (tanpa API key, tanpa akun, tanpa kirim foto ke server mana pun). Foto tidak disimpan ke database — hanya dipakai sesaat, lalu langsung dibuang dari memori. Karena ini pembacaan otomatis (bukan AI yang "paham konteks"), selalu periksa ulang field yang terisi sebelum menyimpan.
